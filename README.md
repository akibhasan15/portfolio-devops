A high-performance, cyber-aesthetic portfolio website for **Akib Hasan**, a DevOps & Cloud Engineer based in Dhaka, BD. Designed with an **Obsidian Void & Electric Azure** design system, featuring real-time Kubernetes story terminals, an interactive HTML5 Canvas cloud network mesh, and smooth GSAP-driven micro-interactions.

---

## ⚡ Key Features

*   🛸 **Cyber Glass Floating Dock Navigation:** Multi-layered frosted glass dock with Electric Azure rim lighting, holographic brand badge (`AKIB.H`) with live cluster health status, and a vibrant gradient `HIRE ME ↗` CTA.
*   🌐 **Interactive Cloud Network Mesh:** Real-time 60fps HTML5 Canvas particle simulation with dynamic cluster nodes and topology links responding magnetically to cursor coordinates.
*   🖥️ **Live Incident Response Terminals:** 3D perspective glassmorphic terminals simulating live Kubernetes cluster monitoring, autoscaling, and DDoS mitigation.
*   🔄 **Dual-Track Infinite Marquee:** Bi-directional counter-scrolling ribbons highlighting core cloud infrastructure and observability tools with edge-fade gradient masks and interactive hover deceleration.
*   💼 **Interactive Experience Accordions:** Expandable job roles with smooth height transitions and staggered duty reveals.
*   🚀 **Production Project Showcase:** Highlights key telecom and enterprise deployments including *My ROBI Application*, *MY CIRKLE APPLICATION*, *Airtel Buzz*, *bdapps*, and more.
*   📱 **100% Mobile Optimized:** Fully responsive with a custom Floating Action Button (FAB) and full-screen mobile menu.
*   🧈 **Smooth Scroll:** Powered by Lenis for buttery-smooth viewport physics.

---

## 🛠️ Tech Stack

*   **Markup:** HTML5 (Semantic & SEO Optimized)
*   **Styling:** Vanilla CSS3 (Custom Variables, Glassmorphism, 3D CSS Transforms, Responsive Media Queries)
*   **Typography:** Google Fonts (`Orbitron`, `Inter`, `Fira Code`)
*   **Logic & Canvas:** Vanilla JavaScript (ES6+), HTML5 Canvas 2D API
*   **Animation Libraries:** GSAP (GreenSock) v3.12.5 & ScrollTrigger
*   **Scroll Engine:** Lenis v1.0.39

## 🚀 Running Locally

Since this project is built entirely with pure web standards, no compilation or bundler step is required.

1. Clone the repository:
   ```bash
   git clone https://github.com/akibhasan15/portfolio-devops.git
   cd portfolio-devops
   ```
2. Open `index.html` directly in your browser, or start a local static server:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node.js npx
   npx serve .
   ```
3. Navigate to `http://localhost:8000` in your web browser.
