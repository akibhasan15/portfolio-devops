# Emir Qassim - Cyber Security Portfolio

This repository branch (`emir-qasim`) contains the source code for the personal portfolio website of Emir Qassim, a Cyber Security Analyst and Digital Forensics specialist based in the UK. The website highlights his academic achievements (BSc Cyber Security & Digital Forensics at Kingston University), professional experience, projects (including Honeypot evaluations), and hands-on skills related to Ethical Hacking, Threat Hunting, Linux, and Network Security.

## Theme & Aesthetic

This branch features a completely custom **Cyberpunk / Hacker aesthetic**, designed to reflect a deep passion for cybersecurity:
*   **Neon-Cyan & Dark Mode:** A stealthy `#0a0a0a` background accented by vibrant `#00ffcc` cyan highlights.
*   **Glitch & Distortion:** Custom CSS glitch animations on headings to simulate digital interference.
*   **Terminal Simulation:** A JavaScript-driven simulated terminal preloader and background elements showing live "SOC monitoring", "Metasploit", and "Threat Hunting" logs.
*   **Typography:** Utilizes `Orbitron` for bold, futuristic headings and `Fira Code` for a developer-centric terminal feel.

## Tech Stack

The portfolio is built with modern, lightweight web technologies focusing on high performance and a rich user experience:

*   **HTML5 & CSS3** (Vanilla CSS with extensive use of CSS variables, clip-paths, and keyframes)
*   **JavaScript (Vanilla)** (Handling terminal simulations, mobile navigation, and interactive accordions)
*   **Lenis** (For smooth, buttery scrolling)

## Features

*   **Terminal Loading Sequence:** An immersive boot-up terminal simulation before revealing the portfolio.
*   **Interactive Mobile Nav:** A sleek, glassmorphic full-screen mobile menu with a custom floating action button (FAB) toggle.
*   **Dynamic Accordions:** Expandable job descriptions and project details to keep the UI clean.
*   **Infinite Marquee:** A continuous scrolling text banner displaying key cybersecurity skills.
*   **Responsive Design:** Fully adapted and fluidly scaled for mobile, tablet, and desktop screens using `vw` and `vh` units.

## File Structure

*   `index.html`: Main HTML structure containing the semantic layout and content.
*   `style.css`: All styling, animations, glitch effects, and responsive breakpoints.
*   `script.js`: Initialization of the terminal typing simulations, Lenis smooth scrolling, and mobile nav toggle logic.
*   `README.md`: This file.

## How to Run

Since the website is built entirely with vanilla web technologies, no build step or package manager is required. 
Simply clone the repository, switch to the `emir-qasim` branch, and open `index.html` in any modern web browser. Alternatively, serve it using a local development server (e.g., VS Code Live Server, or `python -m http.server`).
