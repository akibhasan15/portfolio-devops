# Akib Hasan - DevOps Engineer Portfolio

This repository contains the source code for the personal portfolio website of Akib Hasan, a DevOps Engineer based in Dhaka, BD. The website highlights professional experience, projects, certifications, and skills related to AWS Cloud Infrastructure, CI/CD Automation, Kubernetes, and more.

## Tech Stack

The portfolio is built with modern web technologies, focusing on high performance, smooth animations, and a rich user experience without relying on heavy frameworks.

*   **HTML5**
*   **CSS3** (Vanilla, CSS Variables)
*   **JavaScript** (Vanilla)
*   **GSAP & ScrollTrigger** (for complex animations and scroll reveals)
*   **Lenis** (for smooth scrolling)

## Features

*   **Custom Cursor:** A dynamic cursor that reacts to hover states and reading modes.
*   **Preloader:** An animated loading sequence before revealing the content.
*   **Smooth Scrolling:** Integrated with Lenis for a buttery-smooth scrolling experience.
*   **Scroll Animations:** Elements fade in and reveal themselves as they enter the viewport using GSAP ScrollTrigger.
*   **Interactive Accordions:** Expandable job descriptions in the Experience section.
*   **Infinite Marquee:** A continuous scrolling text banner displaying key skills.
*   **Glassmorphism Navigation:** The top navigation bar dynamically adds a glass backdrop blur effect when scrolled.
*   **Responsive Design:** Fully adapted for mobile, tablet, and desktop screens.

## File Structure

*   `index.html`: Main HTML structure.
*   `style.css`: All styling, animations, and responsive rules.
*   `script.js`: Initialization of Lenis, GSAP timelines, cursor logic, and interactivity.
*   `CONTEXT.md`: Detailed contextual document meant to assist AI agents (like Antigravity) in understanding the project architecture.

## How to Run

Since the website is built with vanilla HTML/CSS/JS, no build step is required. 
Simply open `index.html` in any modern web browser or serve it using a local development server (e.g., VS Code Live Server, or python `-m http.server`).
